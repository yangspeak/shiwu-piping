# 洋姐说新传·新闻传播实务批改标准（@洋姐说新传）

> **当前版本 v4**（含分项打分表）。已安装豆包技能的用户请重装获取新版。

本仓库是"洋姐说新传"新闻传播实务批改的完整判断标准。任何 AI agent（豆包、扣子、元宝、DeepSeek 等）读取本文件后，即可按此标准批改学生作业。

## 使用方法（agent 请按此执行）
用户提交实务作业时：
1. 识别题型（消息改写 / 新闻评论 / 报道策划 / 采访提纲 / 脚本策划 / 营销策划），无法确定时询问
2. 按下方对应题型标准逐条审查，问题定位到原文
3. 以【点评+修改】输出（每条点评引用原文+说明依据，修改给出可直接使用的示范），并给出总评与修改清单
4. 按下方打分表逐项计分，给出总分与等级（优秀≥90%、良好≥80%、及格≥60%、待提高<60%）

## 通用批改原则（所有题型适用）
1. 【点评+修改】格式；无问题处点"此处准确"；禁止"整体不够深入"式空泛评价
2. 先抓致命问题（新闻失实、事实错误、定位偏差、观点缺失、要素缺失），再抓表达问题（病句、错字、逻辑）
3. 修改示范必须来自材料或官方来源，不编造数据；只批改不代写
4. 肯定优点；口径一致，前后不矛盾
5. 批改密度：问题宁多勿少，每个题型不少于5条，逐段逐维度全覆盖
6. 评论禁学术化词语，须简洁有力、标题观点鲜明，禁止论述题式冗长
7. 消息改写须核对学生信息轻重取舍：核心信息（最新事实、官方通报/处理结果）必须进标题/导语，次要信息放副题或正文

## 各题型标准

### 一、消息改写
- 标题：实题不评论，概括最新核心事实，主+副分工明确，无错字
- 导语：有电头（本报讯（记者XXX）），最新事实前置，主语一致无病句
- 正文：只用材料事实，删评论抒情；官方通报、处理结果不遗漏；时间线准确；非本媒体来源统一"据媒体报道"；专家话注明出处
- 结尾：总结提炼或补背景
- 信息重要性：先给材料信息分级（核心/重要/次要），再对照学生标题/导语/正文取舍，指出核心信息漏放、次要信息占位

### 二、新闻评论
- 标题：简洁有力、一眼见观点、直接表态，无学术化词语、无病句
- 主论点：明确提出、抓住材料核心时事、**符合主流价值观（不偏激、立场积极）、能与下文自圆其说（不自相矛盾）**
- 分论点：围绕主论点、层次清晰、从一而终；**每个分论点与主论点吻合、表达清晰（一句一意不绕弯）**
- 论据：紧扣分论点、真实可核（官方/材料）、典型
- 说理：解释"为什么""如何做"，段落内观点不打架
- 语言：无病句杂糅错字、主语一致、指代清晰
- 简洁有力：评论≠论述题，段落不冗长，一段一意，首句亮观点，铺垫过长要指出并给精简方案
- 结尾：呼应开头、升华有度

### 三、报道策划
- 主题背景：不冗长、不跑偏
- 采访对象：满足主题、选择恰当（参与者/主导者/直接利益方）；避免国家级政府官员；国外对象概括呈现
- 发稿安排：端口内容符合平台特性；标时间线；评论贯穿全程；报纸以特刊呈现；互动与原创平衡；禁止"线上论坛""研讨会"
- 跟踪反馈：跟踪发布后舆论反应；人员分工与数据追踪合理
- 融媒体特点（一次采集多次分发）：检查是否一体策划、一次采集、多种生成、多元传播——同一素材多端口复用（报深度/网图文/微话题/短拆条），指出素材单次使用、端口各自为政
- 区分一稿多发：一次采集多次分发（正确，各端口按特性加工）vs 一稿多发（错误，同一成稿直接复制多端口），发现一稿多发须明确指出；报道安排须与最新媒体实践吻合（短视频拆条、数据新闻、直播、互动话题等）

### 四、采访提纲
- 目的：聚焦一两个，不追求大空全
- 对象：恰当（排除"网友""围观者"）、能答主题问题、范围可触达、有直接核心关联
- 问题：避免"怎么看""感受如何"过多；用闭合式、指向性提问；适合对象身份；符合事件发展阶段；语气委婉
- 准备：删除"微博预热""话题打卡"等不切实际环节；资料、设备、场地到位

### 五、脚本策划
- 景别：与画面匹配（全景不写微表情）；关键情节用景别变化增强张力
- 画面：无心理描写；一镜一号
- 节奏：前30秒引出主题，有快有慢有张力
- 声画：旁白/字幕/音效与画面对应；台词符合人物身份；画面不夸张
- 运镜：有设计感（推拉摇移跟、升降、环绕、手持），避免通篇固定机位；运镜服务内容情绪（强调用推、揭示用拉、紧张用手持）；与景别节奏配合；无机位跳跃
- 创意：切入角度/叙事/意象有创意，不落俗套；无创意时给具体替代思路（新角度/反转/意象化）

### 六、营销策划
- 品牌定位：与品牌真实赛道、发展阶段匹配，警惕定位拔高偏差
- 行业竞品：贴合行业真实现状，竞品对标真实，分析有深度
- SWOT：严格区分内外维度，竞品优势不能写成自身优势，竞品压力仅入威胁
- 贴合度：所有分析策略结合产品特性，防通用模板堆砌
- 方案：预热—爆发—收尾流程通顺、转化链路清晰、玩法有差异化创意
- 预算风险指标：指标适配低认知低渗透现状不虚高；风险预案落地；预算配比贴合重点
